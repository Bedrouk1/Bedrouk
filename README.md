## 🇬🇧 English

### Overview

BEDROUK is a bilingual personal portfolio with a dedicated Machine Learning learning area. It brings project presentation and educational content together in one responsive website.

### Highlights

- 🌌 Dark futuristic visual direction with subtle neon accents
- 🌍 Persian and English interface
- 📱 Responsive layout for desktop and mobile
- ✨ Smooth transitions and scroll-based reveal effects
- 🧠 Dedicated Machine Learning Academy with beginner-friendly explanations
- ∑ Mathematical formulas explained symbol by symbol
- 🎞️ Animated visual walkthroughs for each core concept and algorithm
- 🧭 Step-by-step interactive lesson diagrams
- 📚 Clear academy entry point on the main portfolio page
- 💻 Python examples presented in a code-focused learning layout
- 📖 Lessons, explanations, and key learning notes

### Project structure

```text
Bedrouk/
├── index.html       # Main portfolio page
├── academy.html     # Machine Learning learning space
├── README.md        # Project overview and documentation
└── supabase/        # Backend-related project resources
```

### Run locally

1. Clone or download this repository.
2. Open `index.html` in a modern browser.
3. Open `academy.html` to explore the learning area.

No build step is required for the current static pages.

### Deploy with GitHub Pages

1. Open **Settings → Pages** in the repository.
2. Select **Deploy from a branch**.
3. Choose `main` and the `/ (root)` folder.
4. Save and wait for the deployment to finish.

## 🇮🇷 فارسی

### درباره پروژه

BEDROUK یک وب‌سایت شخصی دو‌زبانه است که بخش معرفی، نمایش پروژه‌ها و آکادمی آموزش یادگیری ماشین را در یک محیط یکپارچه جمع می‌کند.

### امکانات

- 🌌 طراحی تیره با حال‌وهوای آینده‌نگر و جزئیات نئونی
- 🌍 رابط فارسی و انگلیسی
- 📱 سازگار با موبایل و دسکتاپ
- ✨ حرکت‌های نرم و انیمیشن هنگام اسکرول
- 🧠 آکادمی آموزش Machine Learning با توضیح مناسب مبتدی‌ها
- ∑ فرمول‌های ریاضی با معنی تک‌تک نمادها و مثال عددی
- 🎞️ موشن اختصاصی برای نمایش سازوکار شش فصل آموزشی
- 🧭 مراحل تعاملی برای دنبال کردن روند اجرای مدل
- 💻 نمونه‌کدهای Python همراه با توضیح

### ساختار فایل‌ها

- `index.html` — صفحه اصلی پورتفولیو
- `academy.html` — محیط آموزشی یادگیری ماشین
- `README.md` — معرفی و راهنمای پروژه
- `supabase/` — منابع مرتبط با بخش بک‌اند

### اجرای محلی

مخزن را دریافت کن و فایل `index.html` را با مرورگر باز کن. برای ورود مستقیم به آکادمی نیز می‌توانی فایل `academy.html` را باز کنی.

### انتشار رایگان

در تنظیمات مخزن، وارد **Settings → Pages** شو، گزینه انتشار از Branch را انتخاب کن و Branch برابر `main` و پوشه `/ (root)` را قرار بده.
