# BEDROUK — Control Center

A personal productivity dashboard for managing daily tasks, projects, learning goals, and notes.

## Features

- Responsive dark futuristic interface with neon accents
- Add, complete, and delete tasks
- Automatic task progress calculation
- Quick notes and a dedicated notes page
- Project overview and learning roadmap
- Local browser storage — no account or backend required
- Built with plain HTML, CSS, and JavaScript

## Run locally

Open `index.html` in a modern browser.

## Publish with GitHub Pages

1. Open the repository **Settings**.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.

## Data & privacy

Tasks and notes are stored in the browser's local storage on the device being used. They are not synced between devices and may be lost if browser data is cleared.
